# OpenBattle Roadmap

## M0 — Bootstrap

- [x] Unreal Engine 5 C++ project scaffold
- [x] Windows, macOS Apple Silicon, Linux targets documented
- [x] Server-authoritative replicated state baseline
- [x] Game design and architecture baseline
- [ ] Pin the exact Unreal Engine version after the first successful local build

## M1 — 3 floors / 12 players

Goal: prove the core loop before investing heavily in art.

- [ ] 3-floor graybox tower
- [ ] 12 starting slots
- [ ] character movement and camera
- [ ] one basic firearm
- [ ] authoritative health, damage, and death
- [ ] immutable origin-floor identity
- [ ] ID Card drop and pickup
- [ ] Security Exchange Box redemption
- [ ] alliance request / accept
- [ ] armband identity placeholder
- [ ] radio placeholder
- [ ] floor pressure states
- [ ] Linux Dedicated Server
- [ ] Windows client test
- [ ] macOS Apple Silicon client test
- [ ] Linux client test

## M2 — Combat feel

- [ ] ADS and recoil
- [ ] reload
- [ ] inventory and pickup
- [ ] weapon tiers
- [ ] armor
- [ ] hit feedback and audio
- [ ] elevator and stair combat playtest

## M3 — Full tower

- [ ] 10 floors
- [ ] 40 slots
- [ ] 4 human Security defenders on Floor 10
- [ ] rank scoring
- [ ] bounty tuning
- [ ] dynamic floor-pressure timeline
- [ ] multi-route vertical transitions

## M4 — Public pre-alpha

- [ ] accounts and matchmaking
- [ ] reconnect handling
- [ ] crash telemetry
- [ ] moderation/reporting basics
- [ ] performance presets
- [ ] packaged Windows, macOS, and Linux releases
